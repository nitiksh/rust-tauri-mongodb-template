# UI (React Frontend)

This folder contains the React frontend for the Tauri application.

## Tech Stack

- React 19
- Vite
- React Router

## Development

```bash
npm install
npm run dev
```

## Pages

- `Inbox.jsx` - View all messages
- `Create.jsx` - Create new message
- `Update.jsx` - Update message
- `Delete.jsx` - Delete message
- `Success.jsx` - Success confirmation
